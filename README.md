# SATURN Analytics — demo pública

Aplicació Streamlit amb **dades completament fictícies**. No inclou CSV reals, noms de clients, marques comercials, contrasenyes ni cap sistema de càrrega.

## Publicació
Puja els quatre fitxers d’aquesta carpeta (no el ZIP) a l’arrel del repositori GitHub i desplega `app.py` a Streamlit Community Cloud.

## Avís
Els 48 indicadors i les gràfiques són exemples sintètics. Aquesta versió no llegeix CSV i no és la futura versió privada. No hi pugis dades reals al repositori públic.
